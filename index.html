How it works

How it works

Three steps, no account, no waiting. Everything happens in your browser.

  1. Upload

    Drop one photo or a whole batch. Vertical and horizontal photos are handled separately, so one batch can mix both.

  2. Adjust

    Pick a border width and color, then a target ratio (4:5 is the Instagram portrait standard). The preview updates every time you change something.

  3. Download

    You get a ZIP of high-quality JPEGs, one file per frame, named after the original photo.

Choosing a mode

Each orientation has its own mode. Border width and color are shared.

Fit
The whole photo is scaled to fit inside the target ratio. Nothing is cropped, but the border can be wider on two sides.
Cover
The photo is cropped from the center so the border is exactly the same on every side.
Add
The target ratio is ignored. The border is simply added around the original photo.

Seamless carousels

Turn on Split horizontals and a horizontal photo is cut into 2 to 5 frames. Post them as a carousel in order and they line up as one wide picture. The border wraps the whole panorama, so it stays continuous between slides. Splitting is not available in Add mode, because that mode has no target frame to divide.

Install it

Bordr is a PWA. Use Install in your browser's address bar, or Add to Home Screen on mobile, to launch it like a regular app.
