# Bordr
A browser-based tool for adding perfectly consistent borders to your photos before posting.

### This project is a work in progress
Bordr solves the annoying and repetitive task of adding a border around your photos for posting. You can select a target aspect ratio, so all your images will have the same dimensions and will be social media-ready, all in one click. There are multiple modes for adding the border and cropping the photos, and it's even possible to slice horizontal pictures to create thoose amazing photo carousels.
